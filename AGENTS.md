# Agent Guidelines — just-dna-format

The agent guidance for this repo lives in **[CLAUDE.md](CLAUDE.md)** — the single source of truth,
kept current with every release. Read that file.

This `AGENTS.md` used to carry a parallel copy for non-Claude-Code agents, but nothing in the repo
loads it, so it drifted: it still described the pre-0.6 world (the 0.5 `RMn` scope, two ROADMAP
trackers where there are now three, five concluded proposals, the 0.4.1/0.5 design threads) long
after the 0.7 cut and the Constitution restructure. A stale second copy is worse than none, so the
content now lives in one place. If your agent reads `AGENTS.md` by convention, follow the pointer
above.
